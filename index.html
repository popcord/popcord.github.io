02 — FAQ

Answers.

Quick answers about the published commands, community and site.

What prefix does the published command list use?+
The command catalogue shows p! as its prefix.
Where can I browse PopCord commands?+
Open the Commands page to search the published list or filter it by category.
How can I report a bug?+
The original FAQ points users to the support server. The published command list also includes /bugs.
Can I use the community chat on this website?+
Yes. The ChatBox page contains an embedded WidgetBot chat, and also provides a link to open Discord directly.
Where can I read about data handling?+
Read the published privacy information. Its statements still need to be checked against the bot's current implementation.
What categories appear in the command catalogue?+
Social, Utility, Admin, Fun, NSFW and Downloader. The NSFW category is clearly labelled in the catalogue.
