Transparency note: this page reflects the privacy information currently published for PopCord. Its technical details have not been checked against the bot’s current source code. The project owner should confirm the described storage, caching and deletion behaviour against the live implementation.

01

How data is used

The published policy says the bot may use stored data for features such as welcoming users when that feature is enabled and handling commands. It also states that data is not used for other purposes and is not shared with third-party websites or services.

02

Information listed as stored

The published policy names the following information as data that may be stored automatically when the bot is added to a Discord server:

  • User ID associated with premium members
  • Guild ID associated with the server prefix and welcome-message setting
  • Prefix, with p! given as the default value

The policy states that this information is deleted when the bot leaves a server. It also says that no other information is stored. A later section separately mentions that message content may be stored for certain commands; that point needs confirmation against the bot implementation.

03

When data may be updated

The published policy says data may be updated when a user sends a message. It adds that some commands may require user input and that potentially sensitive information, such as message content, may need to be stored when those commands are used.

The same policy states that no other actions update the stored information.

04

Temporary caching

The policy says the bot may keep information in an internal cache for a limited period. Once that period ends, the cached information is removed and may be added again when needed.

It also says cached data may be removed earlier, for example if the bot is removed from a server or enters maintenance.

Published cache period: 7 days.

05

Data removal

Automatic removal

The policy says stored server data is removed automatically when the bot is removed from a server, either by being kicked or banned. If the bot is invited again, the same default values described above are added back to the database.

Manual requests

Requests to remove data may be made through the PopCord support server.

Server data deletion

For a Discord server, the policy says proof of server ownership is required. It states that only the server owner may request deletion of that server's data.

User data deletion

Users who want their data removed from the bot database are directed to make a request in the support server.
